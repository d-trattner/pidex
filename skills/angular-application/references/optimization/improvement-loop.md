# Angular skill improvement loop

For each failure:

1. Preserve the immutable run/fixture identity.
2. Reproduce the smallest discriminating case.
3. Classify the primary layer: upstream Angular/Material/Nx drift, module mechanics, skill routing, project convention, general PIDEX workflow, application defect, or benchmark defect.
4. Change one PIDEX optimization variable.
5. Rerun the focused case.
6. Rerun one unaffected regression cohort.
7. Compare quality and efficiency; reject unexplained regressions.
8. Promote through a normal reviewed PIDEX source commit.

Do not bloat the global skill for a project-specific preference. Initiative011 findings can identify candidates but cannot edit module/skill source. Official upstream updates are new pinned candidates with hash/license/diff review and affected cohort reruns.
